HEBERGER FRENCH-STREAM-FULL SUR RENDER
======================================

Version actuelle du projet : 2.2.0
Identifiant Stremio stable : org.frenchstreamfull.addon
Manifeste : https://french-stream-full.onrender.com/manifest.json

DEPLOIEMENT EXISTANT
  1. Le dépôt GitHub est relie au service Render `french-stream-full`.
  2. Pousse les changements sur la branche surveillee par Render (actuellement `main`).
  3. Dans Render, lance un deploiement si le deploiement automatique est desactive.
  4. Attends le statut `Live`, puis verifie `/manifest.json` et `/health`.
  5. Le manifeste doit afficher le nom French-Stream-Full, l'identifiant ci-dessus,
     la version 2.2.0 et les catalogues `fsf-movies` / `fsf-series`.

CONFIGURATION RENDER
  Le fichier `render.yaml` definit les commandes :
       Build : npm install
       Start : node stream-proxy.js
  Render fournit la variable PORT. Le service ecoute sur toutes les interfaces.

INSTALLATION DANS STREMIO
  Stremio > Addons > Installer via URL > coller l'adresse du manifeste ci-dessus.
  Les films utilisent le type `movie`. Les series et anime utilisent `series`;
  les anime sont regroupes dans le catalogue `fsf-series`.

VERIFICATION
  Sous Windows, lance `Verifier-les-flux.cmd`. Le rapport local couvre 10 films,
  10 series et 10 anime, en comparant l'API Render et les adaptateurs locaux.
  Les donnees du rapport sont ecrites dans `verification-fluxes.txt`.

NOTES
  - `data/fsf.json` est ignore par Git ; l'index se reconstruit au fil des recherches.
  - Le service Render gratuit peut s'endormir apres une periode sans requete.
  - En local, `npm run dev` lance `addon.js` sur le port 7000 par defaut.
